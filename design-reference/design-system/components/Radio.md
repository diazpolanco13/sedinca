# Radio

Botón de opción para elegir una sola alternativa de un grupo.

- **Props:** `label` (o `children`), `name` (compartido por el grupo), `value`, `checked` / `defaultChecked`, `onChange`.
- Círculo de 18px. Inactivo: fondo `surface`, borde 1.5px `line-strong`. Activo: anillo `brand` con punto central de 8px `accent`.
- Foco de teclado: contorno 2px `focus-ring`.
