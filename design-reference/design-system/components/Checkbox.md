# Checkbox

Casilla de verificación para selecciones independientes.

- **Props:** `label` (o `children`), `checked` / `defaultChecked`, `onChange`, `name`, `disabled`.
- 18×18px, radio `radius-sm`. Inactiva: fondo `surface`, borde 1.5px `line-strong`. Activa: fondo `brand` con marca `on-brand`.
- Foco de teclado: contorno 2px `focus-ring`.
- Úsala en listas de verificación (entrega de equipos, controles de ronda), no para opciones excluyentes.
